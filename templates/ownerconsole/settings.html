Google sign-in {% if obj.google_client_id %}ON{% else %}OFF{% endif %}

Once the Client ID is saved, the ERP sign-in and sign-up pages show "Sign in with Google" by themselves.

{% include "ownerconsole/_field.html" with f=form.google_client_id %}{% include "ownerconsole/_field.html" with f=form.google_client_secret %}

{% if obj.google_client_secret %}A client secret is saved.{% else %}No client secret saved.{% endif %} The button only needs the Client ID; the secret stays private and is never shown again.

  1. console.cloud.google.com → APIs & Services → Credentials → Create credentials → OAuth client ID → Application type: Web application.
  2. Authorised JavaScript origins: add your ERP address, {{ erp_url }} (and your live domain).
  3. Paste the Client ID and secret here and save. Then open the ERP sign-in page to test.
