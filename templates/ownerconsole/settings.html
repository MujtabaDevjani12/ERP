  1. console.cloud.google.com → APIs & Services → Credentials → Create credentials → OAuth client ID → Application type: Web application.

Backup & restore

One .zip with the whole owner database: plans, companies' subscriptions, invoices, payments (with receipts), your team, these settings and the e-mail log. Companies' own ERP data is not in it - each company backs that up from its own Settings.

{% oicon "download" %}Download backup

Restore from a backup

This replaces everything in the owner database with the file. Anything added after the backup was made is lost. A safety copy of the current data is saved on the server first; if something fails nothing changes. Your sign-in stays only if your account is in the backup.
